# TIC-TAC-TOE
 Tic Tac Toe is a two player strategy game played on a 3×3 grid. One player uses “X” and the other uses “O”. Players take turns placing their symbol in an empty cell.  The objective of the game is to be the first player to get three of their symbols in a row Tic Tac Toe is easy to learn, and develop logical thinking and decision-making skills.
